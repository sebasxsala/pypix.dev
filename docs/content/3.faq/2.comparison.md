A feature comparison between the PyPI website and the intended pypix.dev experience.

## Feature comparison

| Feature                       | pypi.org |       pypix.dev       |
| ----------------------------- | :------: | :-------------------: |
| Package search                |   Yes    |          Yes          |
| Package details               |   Yes    |          Yes          |
| Release history               |   Yes    |          Yes          |
| Project links and classifiers |   Yes    |          Yes          |
| Requirements display          |   Yes    |          Yes          |
| Vulnerability signals         |   Yes    |          Yes          |
| Code/source browser           |    No    |        Planned        |
| Dark mode                     |    No    |          Yes          |
| Keyboard navigation           |    No    |          Yes          |
| Package comparison            |    No    |        Planned        |
| Download charts               | Limited  | Needs external source |

## Why use pypix.dev?

pypix.dev focuses on:

- **Speed** - fast page loads and keyboard-first navigation.
- **Developer experience** - a cleaner, modern UI for evaluating Python packages.
- **Inspection** - release metadata, project files, dependencies, classifiers, and security signals in one place.
- **PyPI focus** - built around Python packaging conventions instead of inherited npm assumptions.
