Solutions to common issues when using pypix.dev.

## Package not found

If a package doesn't appear in search results or shows a 404 error:

1. **Check the package name** - Ensure the name is spelled correctly
2. **Verify it exists on PyPI** - Check [pypi.org](https://pypi.org/) directly
3. **Wait for sync** - Newly published packages may take a few minutes to appear

## Code viewer not loading

If the code viewer shows an error or doesn't load:

1. **Check package size** - Very large packages may take longer to load
2. **Try a specific version** - Use a versioned URL like `/package-name@1.0.0`
3. **Refresh the page** - Clear cache and reload

## Missing features compared to pypi.org

Some features are not yet available:

| Feature              | Status                                  |
| -------------------- | --------------------------------------- |
| Dependents list      | Needs a Python dependency index         |
| Package admin/access | Needs PyPI account-flow redesign        |
| Organization pages   | Planned where PyPI metadata supports it |
| 2FA/account settings | Not planned                             |

## Report an issue

If you encounter a bug or have a feature request:

1. Check the upstream/fork issue tracker configured for this repository.
2. Open a new issue with package name, URL, and reproduction details.
3. Include whether the project exists on PyPI and which endpoint failed.
