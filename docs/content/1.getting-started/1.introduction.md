pypix.dev is a fast, modern way to browse the PyPI registry.

## What is pypix.dev?

pypix.dev is a fast, modern browser for PyPI, focused on a great developer experience for browsing Python packages, viewing documentation, inspecting releases, and exploring code.

## What you can do

- **Search packages** - Quick package search with instant results and infinite scroll
- **Browse source code** - View package source code with syntax highlighting
- **Check security** - See vulnerability warnings and packaging signals
- **Use familiar URLs** - Browse PyPI projects with a cleaner modern interface

## When to use pypix.dev

Use pypix.dev when you want to:

- Quickly find and evaluate Python packages
- Browse package source code without downloading
- Check package security and provenance
- View package metadata in a clean, dark-mode interface
- Navigate with keyboard shortcuts
