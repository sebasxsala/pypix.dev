pypix.dev works in your browser with no installation required.

## Open pypix.dev

Visit [pypix.dev](https://pypix.dev) to start browsing packages.

## Search for a package

1. Press `/` to focus the search bar (or click it)
2. Type a package name
3. Use arrow keys to navigate results
4. Press `Enter` to view the package

## View package details

Each package page shows:

- **README** - Package documentation
- **Versions** - All published versions with release dates
- **Dependencies** - Required packages with version ranges
- **Metadata** - License, repository, maintainers, and more

## Browse source code

1. Click the **Code** tab or press `.`
2. Navigate the file tree
3. Click any file to view its contents with syntax highlighting

## Use PyPI-style URLs

Use project names that match PyPI packages:

| PyPI project URL                 | pypix.dev equivalent               |
| -------------------------------- | ---------------------------------- |
| `pypi.org/project/requests/`     | `pypix.dev/package/requests`       |
| `pypi.org/project/fastapi/`      | `pypix.dev/package/fastapi`        |
| `pypi.org/project/pydantic/2.0/` | `pypix.dev/package/pydantic/v/2.0` |

::tip
pypix.dev is forked from npmx.dev. Some inherited npm compatibility routes still need PyPI-specific redesign.
::
